# 📘 Learning Dart Core Concepts

Hi! 👋

Welcome to my Dart learning repository.

Before I started learning Flutter, I wanted to build a strong foundation in Dart. Instead of just watching tutorials, I practiced every concept by writing code and experimenting on my own.

This repository is where I keep all of my Dart practice. It includes the examples I wrote while learning different concepts, and I'll continue updating it as I learn more.

If you're also learning Dart, I hope these examples help you understand the language a little better.

## 🚀 Running the Code

Clone the repository:

```bash
git clone https://github.com/hamza-hafeez-dev/Learning-Dart-Core-Concepts.git
```

Go to the project folder:

```bash
cd Learning-Dart-Core-Concepts
```

Run any Dart file:

```bash
dart run
```
